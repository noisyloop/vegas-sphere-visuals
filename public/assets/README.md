Optional Cat mode assets. Drop either file here (not committed by default):

- `cat.glb` – a 3D cat model (preferred if present)
- `cat.png` – a cat image, shown on a spinning card

Only add files you have the rights to use. If neither exists, the app builds
its own grey tabby from Three.js primitives. A green-screen background in cat.png is keyed out automatically.
